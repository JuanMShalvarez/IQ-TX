This project serves to implement fully capable, relatively narrowband and low data rate software defined radio transmitter for amateurs.
Goal is to avoid use of FPGA at all costs and utilize analog peripherals of microcontrollers instead. 

Ideally, data input should be done via famous open source software like GNU Radio.

Responsibility of safe usage, including electrical safety, falls entirely on user. 
Same applies to compliance to regulations determined by respective governing bodies/agencies for wireless communications in your area. 
Please consult the band plan of your location where you intend to operate and limitations applying to transmit power.
